# Surya CUDA benchmark

Дата: 2026-09-26

## Цель эксперимента

Проверить возможность ускорения обработки документов за счёт переноса OCR-движка Surya с CPU на GPU.

Основная гипотеза:
- текущий OCR является основным ограничением скорости;
- GPU-ускорение Surya может уменьшить время обработки документов.

---

GPU:
- NVIDIA GeForce RTX 5060 Ti
- VRAM: 8 GB

AI-компоненты:
- LLM: Qwen2.5-7B-Instruct-Q4_K_M

# Эксперимент 1 — Surya CUDA

## Изменения

Создан отдельный экспериментальный Dockerfile:

- surya-ocr/Dockerfile.cuda

Изменения:
- PyTorch CPU заменён на CUDA build:
  - torch 2.7.1+cu128
- устройство:
  - TORCH_DEVICE=cuda

Production-контейнер Surya не изменялся.

## Результат

CUDA окружение:
- PyTorch CUDA успешно работает.
- GPU определяется:
  - NVIDIA GeForce RTX 5060 Ti

Surya CUDA:
- контейнер запускается;
- модели загружаются.

## VRAM

При совместной работе:

Qwen:
- ~6272 MiB

Surya:
- ~1356 MiB

При реальном OCR:

Ошибка:
- CUDA out of memory

Причина:
- недостаточно VRAM для выполнения inference Surya одновременно с текущим Qwen.

## Вывод

Перенос Surya на GPU технически возможен, но текущая конфигурация Qwen + Surya не помещается в 8 GB VRAM.

# Эксперимент 2 — уменьшение GPU layers Qwen

## Изменение

Проверено:

- ngl 99
- ngl 70

Цель:
освободить VRAM для Surya.

## Результат

Qwen ngl99:
- ~6272 MiB VRAM

Qwen ngl70:
- ~6258 MiB VRAM

Изменение:
- около 14 MiB

## Вывод

Изменение количества GPU layers не дало существенного освобождения памяти.

---

# Текущее решение

Не переводить Surya на GPU в текущей конфигурации.

Причина:
- ограничение VRAM;
- текущая схема стабильна;
- простое уменьшение ngl проблему не решает.

---

# Следующие возможные эксперименты

Рассмотреть:

1. Уменьшение потребления памяти Qwen:
   - контекст;
   - параметры запуска;
   - альтернативная квантовка.

2. Оптимизация Surya:
   - batch;
   - параметры распознавания;
   - отключение необязательных компонентов.

3. Изменение аппаратной конфигурации:
   - больше VRAM.

Все следующие изменения выполнять только через отдельные экспериментальные ветки.
