# DocFlow

DocFlow обрабатывает первичные бухгалтерские документы: принимает сканы и фотографии, распознаёт реквизиты и готовит данные для обмена с 1С. Стек включает Go backend, React/Vite frontend, PostgreSQL, файловое хранилище, OCR и опциональную локальную LLM; развёртывание описано через Docker Compose.

Загрузка → OCR и извлечение → проверка или подтверждение → очередь экспорта → XML → обработка в 1С.

| Документ | Назначение |
| --- | --- |
| [Обзор](docs/OVERVIEW.md) | Назначение, возможности и пользователи |
| [Архитектура](docs/ARCHITECTURE.md) | Компоненты, обработка и архитектурные решения |
| [Эксплуатация](docs/OPERATIONS.md) | Конфигурация, диагностика и восстановление |
| [Интеграция с 1С](docs/INTEGRATION_1C.md) | XML, очереди и границы обмена |

Дополнительные специализированные материалы: [развёртывание](README-DEPLOY.md), [инструкция для 1С](ONEC-INTEGRATION.md), [мобильный контур](MOBILE.md), [приёмка](ACCEPTANCE.md), [backend](docflow/README.md). Они могут содержать исторические сведения; поведение и настройки следует сверять с актуальным кодом и конфигурацией.

Для изменений распознавания начните с [устройства OCR и LLM](docs/ARCHITECTURE.md#распознавание-llm-и-финансовые-поля) и [методики Golden Dataset](docs/OPERATIONS.md#контроль-качества-и-golden-dataset); исходные документы и отчёты контрольного набора хранятся отдельно от репозитория.
