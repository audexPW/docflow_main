# Document fields schema experiment

Дата: 2026-09-26

## Цель

Улучшить качество формирования структурированных данных документов.

## Причина эксперимента

В E2E-тестировании документа test_001 выявлены проблемы на этапе извлечения данных:

- OCR корректно извлекает текст;
- таблицы распознаются;
- LLM формирует ответ;
- но часть полей не соответствует ожидаемой схеме проверки.

Основные зоны:

1. Контрактные поля:
- document number;
- contract number;
- document date;
- contract date.

2. Определение ролей:
- продавец;
- покупатель.

3. Бизнес-поля:
- бухгалтерские счета.

## Правило эксперимента

Не изменять production-логику напрямую.

Все изменения выполняются только в отдельной ветке.
