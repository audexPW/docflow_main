# Итоговый вывод по GPU-ускорению OCR (Surya CUDA)

Дата: 2026-09-26

## Цель эксперимента

Проверить возможность переноса OCR-движка Surya на GPU для ускорения обработки документов без потери качества распознавания.

Целевой сценарий:

Qwen LLM на GPU + Surya OCR на GPU

с сохранением:
- распознавания таблиц;
- качества полей;
- текущего бизнес-сценария DocFlow.

---

# Исходная production-конфигурация

GPU:
- NVIDIA GeForce RTX 5060 Ti
- 8 GB VRAM

AI-контур:

LLM:
- Qwen2.5-7B-Instruct-Q4_K_M
- llama.cpp CUDA

OCR:
- Surya OCR CPU

# Проведённые эксперименты

## 1. Перенос Surya OCR на GPU

Проверено:
- CUDA окружение;
- PyTorch CUDA;
- запуск Surya GPU;
- загрузка моделей.

Результат:

Подтверждено:
- Surya CUDA технически работает;
- GPU определяется;
- модели загружаются.

Ограничение:

Одновременная работа:

Qwen GPU + Surya GPU

на RTX 5060 Ti 8 GB приводит к:

CUDA out of memory.

---

## 2. Оптимизация памяти Qwen

Проверено изменение:

-ngl 99 → -ngl 70

Результат:

Существенного освобождения VRAM не получено.

Вывод:

Изменение количества GPU layers не решает ограничение памяти.

---

## 3. Уменьшение контекста Qwen

Проверено:

-c 32768

и

-c 8192

Результат:

Qwen с контекстом 8192:

- около 4.9 GB VRAM;
- освобождение памяти позволило одновременно запустить Qwen и Surya CUDA.

---

## 4. Оптимизация Surya

Проверены варианты:

- PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True;
- RECOGNITION_BATCH_SIZE 16 → 8 → 4;
- DETECTOR_BATCH_SIZE 4 → 2 → 1.

Дополнительно:

- SURYA_TABLE_REC оставлен включённым.

Причина:

Табличное распознавание является критичным функционалом DocFlow.

---

# Итог экспериментов

Получено:

Qwen:
- работает на GPU;
- c8192 снижает потребление памяти.

Surya:
- работает на GPU;
- сервис запускается;
- таблицы поддерживаются.

Но при реальном OCR:

требуется дополнительный блок памяти около 264 MiB.

На RTX 5060 Ti 8 GB возникает:

CUDA out of memory.

---

# Итоговое решение

Перенос Surya OCR на GPU в текущей аппаратной конфигурации НЕ внедряется.

Production-конфигурация остаётся:

Qwen:
GPU

Surya:
CPU

---

# Причина решения

Ограничение связано не с программной поддержкой CUDA.

Ограничение связано с недостаточным объёмом VRAM для одновременной работы:

- LLM;
- OCR;
- табличного распознавания;
- пиковых операций inference.

---

# Будущие варианты развития

Рассматривать:

1. GPU с большим объёмом VRAM:
- 16 GB и выше.

2. Отдельный GPU-контур для OCR.

3. Отдельное исследование изменения модели Qwen:
- только после проверки влияния на качество.
