# Experiment 001 — Contract fields in LLM schema

Дата: 2026-09-26

## Цель

Проверить влияние расширения схемы LLM на качество извлечения реквизитов документов.

## Гипотеза

Добавление отсутствующих полей в LLM schema позволит модели извлекать контрактные данные и уменьшит количество ошибок проверки.

## Изменения

Файл:

docflow/internal/recognize/refine_split.go

Изменено:

- добавлены поля contract_number;
- добавлены поля contract_date;
- уточнено описание date;
- уточнены правила counterparty;
- уточнены правила organization.

## Тестовый контур

Production не изменялся.

Использован отдельный образ:

docflow-backend:test-fields-schema

Контейнер:

docflow-backend-fields-test
